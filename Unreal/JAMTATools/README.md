# JAM TA Tools - Unreal Bridge

Editor-only Unreal Engine bridge for `.jammeta.json` sidecars generated by the Blender/Maya tools.

The plugin registers native `UEditorValidatorBase` validators for imported **Static Meshes and Skeletal Meshes**. If the asset's source FBX has a sibling `.jammeta.json`, Unreal compares LOD0 render vertices, triangles, material sections and UV channels with the DCC-side expectations. Skeletal validation also checks imported maximum skin influences and guards against a suspicious loss of deform bones. Blocking DCC validation errors fail Unreal Data Validation; import-count discrepancies are reported as warnings.

Because it uses Unreal's Data Validation framework, the validator participates in normal Content Browser validation and `-run=DataValidation` CI once the plugin is enabled.

The bridge stays observational: it reports import differences and source validation failures, but does not silently rewrite Unreal import settings.
